# UI Review

## Purpose

Review an existing page before improving it.

## Review Checklist

Inspect:

- HTML structure
- Bootstrap usage
- CSS organization
- JavaScript interactions
- Typography
- Color consistency
- Spacing
- Alignment
- Visual hierarchy
- Accessibility
- Responsiveness
- User experience

## Deliverables

Before editing:

- Current strengths
- Current weaknesses
- UI inconsistencies
- UX issues
- Improvement plan

Do not modify code until approval.
