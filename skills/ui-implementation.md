# UI Implementation

## Goal

Modernize the page while preserving all functionality.

## Rules

Do NOT:

- Change backend logic
- Rename IDs
- Rename form fields
- Break routes
- Remove functionality

Improve:

- Layout
- Typography
- Colors
- Cards
- Buttons
- Forms
- Tables
- Navigation
- Dashboard
- Responsiveness

Use the project's Design System.

Keep Bootstrap compatibility.

Explain every significant change.
